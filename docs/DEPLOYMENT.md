# Deploy HorizonRelay

Cloudflare Pages serves the React build on `PROJECT.pages.dev`. A Pages Function streams `/api/*` requests to a separate HTTPS API origin. The Docker processor runs on the origin host and polls a persistent SQLite queue through the shared local volume. This deployment uses one origin host and durable local storage for both job metadata and files. The Pages Function does no decompilation or compilation.

## Prepare the origin host

1. Use a Linux host with Docker Engine and Compose v2. Confirm the host supports Landlock ABI 3 or later with an enabled Landlock LSM. Allocate space for Cargo vendor sources, build artifacts, and the retained queue. The default processor requests four CPUs, 12 GiB memory, and up to 8 GiB per-job scratch on tmpfs. Scratch usage counts against the container memory limit.
2. Copy the repository to the host. Copy `.env.example` to `.env` and set `HB_PROXY_SECRET` to a long random value such as one generated by `openssl rand -hex 32`. Leave the Ollama variables empty to disable the optional advisor.
3. Run `docker build -f infra/Dockerfile.toolchain -t horizonrelay-toolchain:26.3 .` from the repository root. Then run `docker compose up --build -d` and inspect `docker compose logs --tail 100 api processor`. A healthy processor logs `Processing queue is ready` after testing the job sandbox.
4. Docker provisions the `jobs` named volume automatically. Use local persistent storage with a filesystem quota or dedicated bounded partition. Retain it across service restarts. SQLite WAL requires both processes to share the same local filesystem. Keep a single origin host for this topology.
5. Expose `127.0.0.1:8788` through your HTTPS reverse proxy using an origin hostname with a valid public TLS certificate. Forward raw request and response bodies and allow at least 32 MiB per request. Permit at least 180 seconds for an upload. Keep port 8788 bound to loopback. The Pages secret protects origin API routes.

Substitute your HTTPS origin hostname in this Caddy site block.

```caddyfile
origin.example.com {
    reverse_proxy 127.0.0.1:8788
}
```

For a reduced processor without official native/content packaging, set `HB_PROCESSOR_TARGET=lite` and `HORIZONBRIDGE_ENABLE_NATIVE=0` in `.env`. The lite image supports decompilation and deterministic source generation. It does not require building the Horizon toolchain image.

## Configure Cloudflare Pages

1. Commit the source tree to a Git repository you control. In Cloudflare, open **Workers & Pages**, create a Pages project, and connect that repository and production branch.
2. Set the root directory to `frontend`, the build command to `npm ci && npm run build`, and the build output directory to `dist`. Use Node 24 if the build image asks for a runtime override. `frontend/functions/api/[[path]].js` is the file-based API route and the build copies `_routes.json` and `_headers` from `frontend/public`.
3. In the Pages project settings, set `HB_API_ORIGIN` to the HTTPS origin with no path. Add `HB_PROXY_SECRET` as an encrypted secret with the same value as on the API host. Configure production and preview separately. A preview without the origin secret shows the conversion service as unavailable.
4. Deploy. Use the assigned `pages.dev` URL and check that `/api/config` reports the pinned target and intended toolchain availability. Direct requests to the origin API without the secret should return 403.
5. Upload an original fixture, confirm the job completes, verify the source and report downloads, and inspect the worker logs. For the full profile, repeat with the original `startup.jar` and a supported data JAR. Confirm `cargo horizon-mod check` appears as passed on each applicable package and that game behavior is marked separately.

The origin secret is server-to-server only. The browser receives a private random job token. It uses that token on the same-origin upload, status, cancellation, preview, and download routes until the job expires.

## Browser regression tests

Start the API and worker using `python scripts/dev.py` or Docker plus Vite. Generate `logic.jar` with `python tests/make_fixtures.py ./fixture-output`. Follow the Playwright instructions in the frontend directory if running browser tests. For API integration tests, run `python -m pytest -q` from the repository root.

## Optional Ollama advisor

Set `HB_OLLAMA_URL` to the administrator-controlled Ollama base URL and `HB_OLLAMA_MODEL` to a loaded model. If the endpoint uses bearer authentication, set `HB_OLLAMA_TOKEN` on the API only. The result screen offers advice for opted-in jobs. It sends a bounded subset of the feature and validation report to `/api/chat`. The service treats the response as reviewable advice and leaves package generation deterministic.

Cloudflare reference pages cover [Pages Functions routing](https://developers.cloudflare.com/pages/functions/routing/) and [Pages environment variables and secrets](https://developers.cloudflare.com/pages/functions/bindings/).
